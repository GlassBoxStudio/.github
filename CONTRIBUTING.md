# Contributing

Thanks for your interest in this project.

This is currently a solo-maintained project under active development. Issues and suggestions are welcome — open a GitHub Issue describing what you found or what you'd like to see.

To contribute code:
1. Open an issue first for anything beyond a trivial fix, so the approach can be agreed on up front.
2. Fork the repo and create a feature branch.
3. Keep pull requests focused — one change per PR.
4. Make sure the project's build/lint checks pass before opening the PR.
